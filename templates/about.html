About ML-NIDS

ML-NIDS is a machine learning network intrusion detection system built for my GCU MS Computer Science capstone. It classifies network traffic flows as benign or attack and lets you compare how three models perform.

Dataset

The models are trained on CICIDS2017 from the Canadian Institute for Cybersecurity. Each row is one network flow, described by statistics like packet counts, packet sizes, timing, and TCP flags. After cleaning, the data has 2,517,883 flows and {{ feature_columns|length }} features, and is 83.1% benign and 16.9% attack. Attack types include DoS, DDoS, PortScan, brute force (FTP and SSH), web attacks, botnet traffic, and infiltration.

Models

Random Forest

Combines many decision trees and takes a vote. Handles complex patterns well and shows which features matter most.

Logistic Regression

A simple linear model used as a baseline. Fast and easy to interpret, but can't capture complex patterns.

Linear SVM

Finds the boundary that best separates benign and attack traffic. The linear version is used because a standard SVM is too slow for this much data.

All three use balanced class weights so the smaller attack class isn't ignored, and were trained on a stratified 20% sample with an 80/20 train/test split.

Reading the Metrics

TermMeaning
PrecisionOf the traffic flagged as attacks, the share that really were attacks
RecallOf all real attacks, the share the model caught
F1-scoreA single score that balances precision and recall
False alarmBenign traffic wrongly flagged as an attack
Missed attackAn attack the model labeled as benign
ThresholdHow confident the model must be before it flags traffic as an attack (default 0.50)

Because most traffic is benign, accuracy alone can be misleading. A model that always guessed "benign" would still be 83% accurate, so F1 and recall are better measures here.

Limitations

  • CICIDS2017 is lab-generated traffic, so results may not carry over to real networks.
  • Live traffic capture isn't supported. Files from newer CICFlowMeter versions may use different column names and need to be renamed to match.
  • The app runs locally and only on data you provide. Only upload traffic from networks you're authorized to monitor.
